## 修复：分类修改后分页查询看不到新数据（CategoryMapper.xml）
- 现象：修改分类后，前端列表不更新，需手动刷新；且改「分类名称」时刷新也没变化。
- 根因（后端真 bug）：`CategoryMapper.xml` 的 `<update id="update">` 动态 SQL 只 set 了 status/sort/update_time/update_user，**漏了 name 和 type**。改名称/类型时数据库根本没更新。
- 修复：set 块补上 `<if test="type != null">type = #{type},</if>` 和 `<if test="name != null and name != ''">name = #{name},</if>`。
- 前端交互（待用户配合）：修改保存成功的回调里需重新调用分页查询方法刷新表格，不能等用户 F5。前端工程不在本工作区（D:\project\cjwm 下只有后端 + gitcode/nginx/sky.sql），前端代码位置需用户提供。
